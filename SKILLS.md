# Skills de MiEstacionamientoUC

Las skills del proyecto están en [`.agents/skills`](.agents/skills). Codex puede elegirlas según la tarea. Para invocar una explícitamente, escribe su nombre con `$`, por ejemplo: «Usa `$expo-router` para agregar la pantalla de Reservas».

Los enlaces de la tabla apuntan a los repositorios originales. Las licencias publicadas por Expo, Prisma y Supabase están en [`LICENSES`](.agents/skills/LICENSES). La skill de Vercel declara su licencia MIT en su [`SKILL.md`](.agents/skills/vercel-react-best-practices/SKILL.md).

| Área | Skills | Uso |
| --- | --- | --- |
| Diseño UI/UX | [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) | `ui-ux-pro-max` para diseñar y revisar pantallas, sistemas visuales y accesibilidad de la app móvil y el panel. |
| App móvil | [Expo Skills](https://github.com/expo/skills) | `expo-overview`, `expo-project-structure` y `expo-router` para estructura y navegación. `expo-dev-client` para compilaciones locales y `expo-data-fetching` para las consultas a la API. `expo-native-ui` para controles y patrones nativos. `expo-design-system` para el tema y los componentes reutilizables. |
| Implementación del MVP | [`implementar-spec`](.agents/skills/implementar-spec/SKILL.md) | Implementar una spec del repo, verificar sus criterios y registrar evidencia en el índice. |
| Panel web | [Vercel Agent Skills](https://github.com/vercel-labs/agent-skills/tree/main/skills/react-best-practices) | `vercel-react-best-practices` para componentes, carga de datos y tamaño del bundle en React/Vite. |
| API y base de datos | [Prisma Skills](https://github.com/prisma/skills) · [Supabase Agent Skills](https://github.com/supabase/agent-skills/tree/main/skills/supabase-postgres-best-practices) | `prisma-cli` y `prisma-client-api` para migraciones y consultas con Prisma 7. `supabase-postgres-best-practices` para índices y transacciones al implementar asignaciones concurrentes. |
